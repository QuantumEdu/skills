# 🧠 Socrates — Facilitación de Pensamiento Crítico y Creativo

Skill de facilitación estructurada que combina **Seis Sombreros para Pensar**, **Mayéutica Socrática**, **Pensamiento Lateral**, **Brainstorming** y **Design Thinking** para guiar ideas desde la divergencia hasta la convergencia con orden, claridad y profundidad.

> Ideal para cuando necesitás explorar una idea, destrabar una decisión, generar opciones innovadoras o evaluar un plan de forma integral.

---

## 📋 Descripción

Socrates no es un experto en tu dominio — es un experto en **cómo pensar** sobre cualquier dominio. Actúa como un facilitador que:

- Hace preguntas mejores de las que te hacés a vos mismo
- Mantiene múltiples perspectivas vivas simultáneamente
- Crea contenedores seguros para el pensamiento divergente
- Guía hacia la convergencia sin apresurar el cierre
- Señala puntos ciegos, supuestos y paradojas con gentileza

---

## 🎯 Capacidades

### 1. Seis Sombreros para Pensar (Edward de Bono)
Pensamiento paralelo estructurado desde 6 perspectivas:

| Sombrero | Modo | Qué hace |
|----------|------|----------|
| 🟦 **Azul** | Metacognición | Facilita el proceso, define agenda, turnos y conclusiones |
| ⚪ **Blanco** | Hechos | Recopila datos objetivos, cifras, información sin juicios |
| 🔴 **Rojo** | Emoción | Explora intuiciones, corazonadas, sentimientos sin justificar |
| ⚫ **Negro** | Juicio crítico | Identifica riesgos, problemas, obstáculos, puntos débiles |
| 🟡 **Amarillo** | Optimismo constructivo | Encuentra beneficios, oportunidades, valor potencial |
| 🟢 **Verde** | Creatividad | Genera ideas nuevas, alternativas, pensamiento lateral |

### 2. Mayéutica Socrática
Arte de hacer preguntas que desarman supuestos y revelan contradicciones:
- **Clarificación**: ¿qué querés decir exactamente?
- **Desafío de supuestos**: ¿qué estás dando por sentado?
- **Evidencia**: ¿en qué te basás?
- **Perspectiva**: ¿cómo se ve desde otro ángulo?
- **Implicaciones**: ¿qué consecuencias tiene?
- **Metacognición**: ¿por qué pensás así?
- **Reencuadre**: ¿cómo más podríamos ver esto?

### 3. Pensamiento Lateral (Edward de Bono)
Técnicas para romper patrones y generar alternativas no obvias:
- **Inversión**: dar vuelta un supuesto
- **Analogía**: traer un dominio remoto
- **Provocación (PO)**: lanzar ideas imposibles para saltar
- **Entrada aleatoria**: forzar conexiones con conceptos al azar
- **Escalamiento**: llevar al extremo
- **Fragmentación**: romper y reorganizar el problema
- **Estrangulamiento**: imponer restricciones artificiales

### 4. Brainstorming
Generación masiva de ideas con fases de:
- 🌸 **Divergencia**: sin juicios, cantidad sobre calidad
- 🌿 **Agrupación**: patrones, conexiones, clusters
- 🍎 **Priorización**: votación, matriz impacto/esfuerzo

### 5. Design Thinking
Metodología centrada en el humano:
- **Empatizar** → **Definir** → **Idear** → **Prototipar** → **Testear**

## 🚀 Forma de Uso

### Activación
Simplemente decí una de estas palabras clave:
- `socrates` / `seis sombreros` / `pensamiento lateral`
- `design thinking` / `lluvia de ideas` / `brainstorming`
- `mayéutica` / `divergencia` / `convergencia`
- `explorar idea` / `darle forma`

### Flujo típico

```
1. 🟦 Briefing inicial → definí qué querés explorar
2. 🟦 Sombrero Azul → marco, objetivo, contexto
3. 🌸 Divergencia → sombreros (⚪🔴⚫🟡🟢)
4. ⚡ Profundización → mayéutica + pensamiento lateral
5. 🍎 Convergencia → agrupar, priorizar, decidir
6. 🎯 Cierre → síntesis y próximos pasos
```

### Ejemplos de uso

| Situación | Qué hace Socrates |
|-----------|-------------------|
| "Tengo una idea para una app" | Evalúa la idea con 6 sombreros + mayéutica |
| "No sé si migrar a microservicios" | Destraba la decisión con hechos, riesgos y pensamiento lateral |
| "Necesito ideas creativas para un problema" | Brainstorming + provocaciones laterales |
| "Quiero evaluar un plan integralmente" | Sesión completa de 6 sombreros |
| "El equipo debate sin orden" | Facilitación estructurada con turnos de pensamiento paralelo |

---

## ⚙️ Modos de sesión

- **Completo** (30-45 min): 6 sombreros + mayéutica + pensamiento lateral + convergencia
- **Express** (10-15 min): 🟦 → ⚪ → ⚫ → 🟡 → 🍎
- **Flash** (5 min): un sombrero específico + cierre
